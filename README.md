# YouTube Chat Width & Popout Hider

YouTube のライブ配信ページで、チャット欄の横幅をドラッグで変えられるようにする Chrome 拡張機能です。
チャットをポップアウト（別ウィンドウ表示）している間は、ページ内のチャット領域を自動で閉じます。

## どんな問題を解決するか

YouTube のチャット欄は幅が固定で、長いコメントが折り返されて読みにくかったり、逆に動画をもっと大きく見たくても縮められなかったりします。
この拡張機能を入れると、チャット欄の左端をつかんで好きな幅に調整でき、その幅は次に配信を開いたときも維持されます。

また、チャットをポップアウトして別ウィンドウで読んでいるとき、ページ内のチャット欄は空いたままになります。
この拡張機能はポップアウト中であることを検知してページ内のチャット欄を閉じ、ポップアウトを閉じれば元に戻します。
シアターモードなら、ポップアウト中は動画がページの横幅いっぱいに表示されます。

## 使い始めるには

Chrome ウェブストアには公開していないため、フォルダを直接読み込みます。

1. このフォルダ一式を PC の任意の場所に置く。
2. Chrome のアドレスバーに `chrome://extensions` と入力して開く。
3. 右上の「デベロッパー モード」をオンにする。
4. 「パッケージ化されていない拡張機能を読み込む」を押し、このフォルダを選ぶ。
5. YouTube の配信ページを開いている場合は、そのページを再読み込みする。

以上で有効になります。
拡張機能のアイコンはツールバーに表示され、クリックすると設定画面が開きます。

## できること

### チャット欄の幅を変える

配信ページでチャット欄の左端にマウスを合わせると、縦に細い青い帯（ハンドル）が表示されます。
その帯を左右にドラッグすると、チャット欄の幅が変わり、動画プレーヤーの大きさも合わせて変わります。
通常表示とシアターモードのどちらでも同じ操作で変えられます。

ハンドルをダブルクリックすると、YouTube 標準の幅に戻ります。
変えた幅は保存され、別の配信を開いたときやブラウザを再起動したときにも引き継がれます。

ツールバーのアイコンから開く設定画面でも、幅を数値（px）で指定したり、「既定に戻す」ボタンで標準の幅に戻したりできます。

### ポップアウト中はページ内チャットを閉じる

チャット欄右上のメニュー（縦三点）から「チャットをポップアウト」を選ぶと、チャットが別ウィンドウで開きます。
このとき、ページ内のチャット欄は自動で閉じられ、チャットのあった場所は動画や関連動画に使われます。
ポップアウトのウィンドウを閉じると、ページ内のチャット欄がふたたび表示されます。

ポップアウト中にページ内のチャット欄を自分で開き直した場合、拡張機能はそれを閉じ直しません。
この自動で閉じる動作が不要なときは、設定画面の「ポップアウト中はページ内チャットを非表示」のチェックを外してください。

## 対応範囲

- YouTube のライブ配信ページ（`https://www.youtube.com/watch?v=...`）で、ライブチャットが表示されている場合に動作します。
- 通常の動画ページでは何もしません。関連動画欄の幅は変わりません。
- チャットの縦方向のサイズは変えられません。横幅のみ対象です。
